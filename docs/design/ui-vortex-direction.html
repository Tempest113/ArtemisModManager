Should the Mods page stay two-pane? Four ways to lay out the same job (the one with a highlighted border is the recommendation):

Two panes, collapsible library

Irony's layout. The library folds into a thin strip when you're done picking, so the load order gets the full width.

Two panes, fixed

Irony as is. Always both lists, but names truncate and there's no room for details.

One table (Vortex)

Every installed mod in one list with toggles; "load order" is a sort mode. Simplest, but adding and ordering blur together.

Load order + add drawer

The playset fills the page; "Add mods" opens a side drawer or Ctrl+K search. Focused, but browsing your library is a step away.
